## 1. 迴圈概述
迴圈是程式設計中用於重複執行某段程式碼的結構。Python 提供兩種主要迴圈：
- **`while` 迴圈**：當條件成立時持續執行，直到條件為 `False`。
- **`for` 迴圈**：遍歷可迭代物件（如列表、字串、範圍）的元素。

## 2. while 迴圈
`while` 迴圈在指定條件為 `True` 時重複執行程式碼區塊。

### 語法結構
```python
while 條件:
    # 執行程式碼
```
- **注意**：
  - 條件必須最終變為 `False`，否則會導致無限迴圈。
  - 縮排定義迴圈內的程式碼區塊。

### 程式碼範例 1：計數器
```python
# 使用 while 迴圈計數
count = 1
while count <= 5:
    print(f"計數：{count}")
    count += 1  # 遞增計數器
print("迴圈結束！")
```
- **說明**：
  - `count += 1` 等價於 `count = count + 1`，確保條件最終變為 `False`。
  - 迴圈執行 5 次，輸出 1 到 5。
- **預期輸出**：
```
計數：1
計數：2
計數：3
計數：4
計數：5
迴圈結束！
```

### 程式碼範例 2：使用者輸入控制
```python
# 重複提示使用者輸入，直到輸入 "quit"
while True:
    user_input = input("請輸入文字（輸入 quit 退出）：")
    if user_input == "quit":
        break
    print(f"您輸入的是：{user_input}")
print("程式結束！")
```
- **說明**：
  - `while True` 創建無限迴圈，需用 `break` 退出。
  - `break` 立即終止迴圈。
- **範例輸出**：
```
請輸入文字（輸入 quit 退出）：Hello
您輸入的是：Hello
請輸入文字（輸入 quit 退出）：Python
您輸入的是：Python
請輸入文字（輸入 quit 退出）：quit
程式結束！
```

## 3. for 迴圈
`for` 迴圈用於遍歷可迭代物件（如列表、字串、`range()`），逐一處理每個元素。

### 語法結構
```python
for 變數 in 可迭代物件:
    # 執行程式碼
```

### 程式碼範例 3：遍歷列表
```python
# 遍歷水果列表
fruits = ["蘋果", "香蕉", "橘子"]
for fruit in fruits:
    print(f"水果：{fruit}")
```
- **說明**：
  - `fruit` 依次取列表中的每個元素。
  - 迴圈自動在遍歷完所有元素後結束。
- **預期輸出**：
```
水果：蘋果
水果：香蕉
水果：橘子
```

### 程式碼範例 4：使用 range()
```python
# 使用 range() 產生數字序列
for i in range(1, 6):  # 從 1 到 5
    print(f"數字：{i}")
```
- **說明**：
  - `range(1, 6)` 產生 1 到 5 的整數序列（不包含 6）。
  - `range(start, stop, step)` 可指定起始、結束和步進值。
- **預期輸出**：
```
數字：1
數字：2
數字：3
數字：4
數字：5
```

## 4. 巢狀迴圈
巢狀迴圈是指在一個迴圈內包含另一個迴圈，常用於處理多維資料結構（如表格或矩陣）。

### 程式碼範例 5：巢狀 for 迴圈
```python
# 列印九九乘法表
for i in range(1, 10):
    for j in range(1, 10):
        print(f"{i} x {j} = {i * j}", end="\t")
    print()  # 換行
```
- **說明**：
  - 外層迴圈控制行（`i`），內層迴圈控制列（`j`）。
  - `end="\t"` 使輸出以製表符分隔，保持對齊。
  - `print()` 在每行結束時換行。
- **預期輸出**：
```
1 x 1 = 1	1 x 2 = 2	1 x 3 = 3	1 x 4 = 4	1 x 5 = 5	1 x 6 = 6	1 x 7 = 7	1 x 8 = 8	1 x 9 = 9	
2 x 1 = 2	2 x 2 = 4	2 x 3 = 6	2 x 4 = 8	2 x 5 = 10	2 x 6 = 12	2 x 7 = 14	2 x 8 = 16	2 x 9 = 18	
...
9 x 1 = 9	9 x 2 = 18	9 x 3 = 27	9 x 4 = 36	9 x 5 = 45	9 x 6 = 54	9 x 7 = 63	9 x 8 = 72	9 x 9 = 81	
```

## 5. break 與 continue
- **`break`**：立即終止當前迴圈，跳到迴圈外的程式碼。
- **`continue`**：跳過當前迴圈的剩餘部分，直接進入下一次迭代。

### 程式碼範例 6：break 與 continue
```python
# 示範 break 和 continue
for num in range(1, 10):
    if num == 5:
        break  # 當 num 等於 5 時終止迴圈
    print(f"數字：{num}")

print("--- 分隔線 ---")

for num in range(1, 10):
    if num % 2 == 0:
        continue  # 跳過偶數
    print(f"奇數：{num}")
```
- **說明**：
  - `break` 在 `num == 5` 時終止迴圈，後續數字不輸出。
  - `continue` 跳過偶數，只輸出奇數。
- **預期輸出**：
```
數字：1
數字：2
數字：3
數字：4
--- 分隔線 ---
奇數：1
奇數：3
奇數：5
奇數：7
奇數：9
```

## 6. 課堂練習
請撰寫一個 Python 程式，完成以下任務：
1. 提示使用者輸入一個正整數 `n`。
2. 使用 `for` 迴圈計算 1 到 `n` 的總和。
3. 使用 `while` 迴圈列印從 `n` 倒數到 1。
4. 額外挑戰：檢查輸入是否為正整數，若不是則提示重新輸入。

### 參考解答
```python
# 取得使用者輸入並檢查是否為正整數
while True:
    n = input("請輸入一個正整數：")
    if n.isdigit() and int(n) > 0:
        n = int(n)
        break
    print("請輸入有效的正整數！")

# 使用 for 迴圈計算總和
total = 0
for i in range(1, n + 1):
    total += i
print(f"1 到 {n} 的總和是：{total}")

# 使用 while 迴圈倒數
count = n
while count >= 1:
    print(f"倒數：{count}")
    count -= 1
```
- **說明**：
  - `isdigit()` 檢查輸入是否為數字，確保有效輸入。
  - `for` 迴圈累加 1 到 `n`。
  - `while` 迴圈從 `n` 遞減到 1。
- **範例輸出**：
```
請輸入一個正整數：5
1 到 5 的總和是：15
倒數：5
倒數：4
倒數：3
倒數：2
倒數：1
```

## 7. 常見問題與疑難排解
- **問題**：程式進入無限迴圈。
  - **解決**：檢查 `while` 迴圈的條件是否能變為 `False`，或是否正確更新計數器。
- **問題**：`IndentationError`。
  - **解決**：確保迴圈內程式碼正確縮排（4 個空格）。
- **問題**：`range()` 未包含預期數字。
  - **解決**：記住 `range(start, stop)` 不包含 `stop`，例如 `range(1, 5)` 產生 1 到 4。
