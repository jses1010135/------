## 1. 什麼是資料型態與變數？
在 Python 中，**資料型態**定義了資料的種類與操作方式，例如數字、文字或真假值。**變數**是用來儲存資料的容器，透過變數名稱可以存取和操作資料。Python 是一種動態型別語言，無需顯式宣告變數的型態，Python 會根據賦值自動推斷。

### 變數命名規則
- 變數名稱只能包含字母（a-z, A-Z）、數字（0-9）和底線（_）。
- 變數名稱不能以數字開頭。
- 避免使用 Python 保留字（如 `if`, `for`, `print`）。
- 建議使用有意義的名稱，遵循小寫字母與底線分隔的慣例（例如 `user_name`）。
- Python 對大小寫敏感（`Age` 和 `age` 是不同變數）。

## 2. 基本資料型態
Python 提供多種內建資料型態，本週重點介紹以下四種：
- **整數 (int)**：無小數點的數字，例如 `42`、`-10`。
- **浮點數 (float)**：帶小數點的數字，例如 `3.14`、`-0.001`。
- **字串 (str)**：文字資料，用單引號 `'` 或雙引號 `"` 包圍，例如 `"Hello"`。
- **布林 (bool)**：表示真假的邏輯值，只有 `True` 和 `False`。

### 程式碼範例 1：基本資料型態與變數
```python
# 定義不同型態的變數
age = 25           # 整數
height = 175.5     # 浮點數
name = "Alice"     # 字串
is_student = True  # 布林

# 輸出變數值與型態
print(f"姓名: {name}, 型態: {type(name)}")
print(f"年齡: {age}, 型態: {type(age)}")
print(f"身高: {height}, 型態: {type(height)}")
print(f"是學生嗎? {is_student}, 型態: {type(is_student)}")
```
- **說明**：
  - `type()` 函式用於檢查變數的資料型態。
  - `f-string` 用於格式化輸出，嵌入變數值。
- **預期輸出**：
```
姓名: Alice, 型態: <class 'str'>
年齡: 25, 型態: <class 'int'>
身高: 175.5, 型態: <class 'float'>
是學生嗎? True, 型態: <class 'bool'>
```

## 3. 輸入與輸出
Python 使用 `input()` 函式接收使用者輸入，並使用 `print()` 函式輸出結果。`input()` 預設傳回字串型態，若需其他型態，必須進行型別轉換。

### 程式碼範例 2：簡單輸入與輸出
```python
# 取得使用者輸入
name = input("請輸入您的姓名：")
age = input("請輸入您的年齡：")

# 輸出問候訊息
print(f"您好，{name}！您今年 {age} 歲。")
```
- **說明**：
  - `input()` 提示使用者輸入，傳回值儲存到變數。
  - 注意：`age` 在此為字串型態，若需進行數值運算，必須轉換型態。
- **範例輸出**：
```
請輸入您的姓名：Bob
請輸入您的年齡：30
您好，Bob！您今年 30 歲。
```

## 4. 型別轉換
Python 允許將資料從一種型態轉換為另一種型態，常見的型別轉換函式包括：
- `int()`：轉換為整數，例如 `int("123")` → `123`。
- `float()`：轉換為浮點數，例如 `float("3.14")` → `3.14`。
- `str()`：轉換為字串，例如 `str(42)` → `"42"`。
- `bool()`：轉換為布林，例如 `bool(0)` → `False`，`bool(1)` → `True`。

### 程式碼範例 3：型別轉換與數值運算
```python
# 取得使用者輸入的年齡（字串）
age = input("請輸入您的年齡：")

# 將字串轉換為整數
age = int(age)

# 計算明年年齡
next_year_age = age + 1

# 輸出結果
print(f"明年您將是 {next_year_age} 歲。")
```
- **說明**：
  - `input()` 傳回字串，必須使用 `int()` 轉換為整數才能進行加法運算。
  - 若輸入非數字（例如 `"abc"`），`int()` 會引發 `ValueError`。
- **範例輸出**：
```
請輸入您的年齡：25
明年您將是 26 歲。
```

### 程式碼範例 4：浮點數與字串轉換
```python
# 取得使用者輸入的身高（單位：公分）
height_cm = input("請輸入您的身高（公分）：")

# 轉換為浮點數
height_cm = float(height_cm)

# 將公分轉換為公尺
height_m = height_cm / 100

# 將浮點數轉換為字串以進行格式化
height_m_str = str(height_m)

# 輸出結果
print(f"您的身高是 {height_m} 公尺。")
print("字串格式的身高：" + height_m_str + " 公尺")
```
- **說明**：
  - `float()` 將輸入字串轉為浮點數，允許小數點輸入。
  - `str()` 將數字轉為字串，適用於字串拼接（使用 `+` 運算子）。
- **範例輸出**：
```
請輸入您的身高（公分）：175.5
您的身高是 1.755 公尺。
字串格式的身高：1.755 公尺
```

## 5. 布林型態與邏輯值
布林型態 (`bool`) 只有兩個值：`True` 和 `False`，常用於條件判斷。Python 中許多值會被轉換為布林值：
- **轉為 `False`**：`0`, `0.0`, `""`（空字串）, `None`, 空集合等。
- **轉為 `True`**：非零數字、非空字串等。

### 程式碼範例 5：布林型態應用
```python
# 定義變數
is_adult = True
age = 20

# 使用布林值與條件
if is_adult:
    print("您是成年人！")

# 將數字轉換為布林
has_age = bool(age)
print(f"年齡轉為布林：{has_age}")

# 空字串轉為布林
empty_string = ""
is_empty = bool(empty_string)
print(f"空字串轉為布林：{is_empty}")
```
- **說明**：
  - `if` 語句使用布林值進行條件判斷（後續週次詳述）。
  - `bool()` 顯示不同值的布林轉換結果。
- **預期輸出**：
```
您是成年人！
年齡轉為布林：True
空字串轉為布林：False
```

## 7. 常見問題與疑難排解
- **問題**：`ValueError: invalid literal for int()`。
  - **解決**：輸入非數字（例如 `"abc"`）導致 `int()` 失敗，需檢查使用者輸入或使用例外處理（第12週介紹）。
- **問題**：字串拼接時出現 `TypeError`。
  - **解決**：確保使用 `+` 拼接時所有物件都是字串，使用 `str()` 轉換非字串值。
- **問題**：浮點數輸出過多小數位。
  - **解決**：使用 f-string 的格式化，例如 `{height_m:.2f}` 限制顯示 2 位小數。
