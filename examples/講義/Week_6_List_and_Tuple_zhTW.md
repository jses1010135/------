## 1. 列表與元組概述
列表和元組是 Python 中用於儲存多個資料項的序列型資料結構。它們的主要區別在於：
- **列表 (`list`)**：可變（mutable），可以修改內容，定義使用方括號 `[]`。
- **元組 (`tuple`)**：不可變（immutable），內容創建後無法修改，定義使用圓括號 `()`。

### 共同特性
- 都是有序序列，支援索引（從 0 開始）和切片。
- 可儲存不同型態的資料（例如數字、字串、其他列表等）。
- 支援迭代（可用 `for` 迴圈遍歷）。

### 程式碼範例 1：列表與元組基本操作
```python
# 定義列表和元組
fruits_list = ["蘋果", "香蕉", "橘子"]
numbers_tuple = (1, 2, 3, 4)

# 訪問元素
print(f"列表第一個元素：{fruits_list[0]}")
print(f"元組最後一個元素：{numbers_tuple[-1]}")

# 切片
print(f"列表切片：{fruits_list[1:3]}")
print(f"元組切片：{numbers_tuple[:2]}")

# 長度
print(f"列表長度：{len(fruits_list)}")
print(f"元組長度：{len(numbers_tuple)}")
```
- **說明**：
  - 索引和切片語法與字串相同（參見第5週）。
  - `len()` 傳回序列中的元素數量。
- **預期輸出**：
```
列表第一個元素：蘋果
元組最後一個元素：4
列表切片：['香蕉', '橘子']
元組切片：(1, 2)
列表長度：3
元組長度：4
```

## 2. 列表操作
列表是可變的，支援新增、修改、刪除元素等操作。以下是常用方法：
- `append(item)`：在列表末尾添加元素。
- `insert(index, item)`：在指定索引插入元素。
- `remove(item)`：移除第一個匹配的元素。
- `pop(index)`：移除並傳回指定索引的元素（預設移除最後一個）。
- `clear()`：清空列表。
- `index(item)`：傳回第一個匹配元素的索引。
- `count(item)`：統計元素出現次數。
- `sort()`：對列表進行排序（修改原列表）。
- `reverse()`：反轉列表順序。

### 程式碼範例 2：列表操作
```python
# 定義一個列表
items = ["筆", "書", "橡皮擦"]

# 添加元素
items.append("鉛筆")
print(f"添加後：{items}")

# 插入元素
items.insert(1, "筆記本")
print(f"插入後：{items}")

# 移除元素
items.remove("書")
print(f"移除後：{items}")

# 彈出元素
popped_item = items.pop()
print(f"彈出元素：{popped_item}, 列表：{items}")

# 排序
numbers = [3, 1, 4, 1, 5]
numbers.sort()
print(f"排序後：{numbers}")

# 反轉
numbers.reverse()
print(f"反轉後：{numbers}")
```
- **說明**：
  - `append()` 和 `insert()` 用於添加元素。
  - `remove()` 和 `pop()` 用於刪除元素，`pop()` 還傳回被刪除的元素。
  - `sort()` 預設按升序排列，`reverse()` 改變元素順序。
- **預期輸出**：
```
添加後：['筆', '書', '橡皮擦', '鉛筆']
插入後：['筆', '筆記本', '書', '橡皮擦', '鉛筆']
移除後：['筆', '筆記本', '橡皮擦', '鉛筆']
彈出元素：鉛筆, 列表：['筆', '筆記本', '橡皮擦']
排序後：[1, 1, 3, 4, 5]
反轉後：[5, 4, 3, 1, 1]
```

## 3. 元組操作
元組是不可變的，無法直接修改其內容，但支援索引、切片和一些基本操作。元組常用於儲存固定、不需更改的資料。

### 程式碼範例 3：元組操作
```python
# 定義元組
coordinates = (10, 20, 30)

# 訪問元素
print(f"第一個座標：{coordinates[0]}")

# 切片
print(f"前兩個座標：{coordinates[:2]}")

# 解包（unpacking）
x, y, z = coordinates
print(f"解包後：x={x}, y={y}, z={z}")

# 檢查元素是否存在
print(f"20 是否在元組中：{20 in coordinates}")

# 合併元組
new_tuple = coordinates + (40, 50)
print(f"合併後：{new_tuple}")
```
- **說明**：
  - 元組支援索引和切片，但不可修改（如無法使用 `append()`）。
  - 解包允許將元組元素直接賦值給多個變數。
  - 使用 `+` 合併元組，創建新元組。
- **預期輸出**：
```
第一個座標：10
前兩個座標：(10, 20)
解包後：x=10, y=20, z=30
20 是否在元組中：True
合併後：(10, 20, 30, 40, 50)
```

## 4. 巢狀資料結構
列表和元組可以包含其他列表或元組，形成巢狀結構，常用於表示複雜資料，如表格或多維陣列。

### 程式碼範例 4：巢狀列表
```python
# 定義巢狀列表（模擬成績表）
grades = [
    ["Alice", 85, 90],  # [姓名, 數學, 英文]
    ["Bob", 78, 92],
    ["Cathy", 95, 88]
]

# 訪問巢狀元素
print(f"Alice 的數學成績：{grades[0][1]}")

# 修改巢狀元素
grades[1][2] = 95  # 修改 Bob 的英文成績
print(f"修改後的成績表：{grades}")

# 遍歷巢狀列表
for student in grades:
    print(f"學生：{student[0]}, 平均成績：{(student[1] + student[2]) / 2}")
```
- **說明**：
  - `grades[0][1]` 訪問第一個學生的數學成績。
  - 巢狀列表可透過索引修改，但巢狀元組不可修改。
  - 使用 `for` 迴圈遍歷，計算每位學生的平均成績。
- **預期輸出**：
```
Alice 的數學成績：85
修改後的成績表：[['Alice', 85, 90], ['Bob', 78, 95], ['Cathy', 95, 88]]
學生：Alice, 平均成績：87.5
學生：Bob, 平均成績：86.5
學生：Cathy, 平均成績：91.5
```

## 5. 列表與元組的選擇
- **使用列表**：當資料需要經常修改（如添加、刪除、排序）。
- **使用元組**：當資料固定不變（如座標、設定值），或需要更高的記憶體效率。
- **注意**：元組執行速度略快，且不可變性提供資料保護。

## 6. 課堂練習
請撰寫一個 Python 程式，完成以下任務：
1. 提示使用者輸入 3 個商品名稱，儲存到一個列表。
2. 將列表轉換為元組，顯示元組內容。
3. 在列表中添加一個新商品，並對列表進行排序。
4. 創建一個巢狀列表，包含每個商品的名稱和隨機價格（範圍 10-100）。
5. 輸出巢狀列表，並計算所有商品的平均價格。

### 參考解答
```python
import random

# 取得使用者輸入的商品
items = []
for i in range(3):
    item = input(f"請輸入第 {i+1} 個商品名稱：")
    items.append(item)
print(f"商品列表：{items}")

# 轉換為元組
items_tuple = tuple(items)
print(f"商品元組：{items_tuple}")

# 添加新商品並排序
items.append(input("請輸入一個新商品名稱："))
items.sort()
print(f"排序後的列表：{items}")

# 創建巢狀列表（商品與隨機價格）
item_prices = [[item, random.randint(10, 100)] for item in items]
print(f"商品與價格：{item_prices}")

# 計算平均價格
total_price = sum(price for _, price in item_prices)
average_price = total_price / len(item_prices)
print(f"平均價格：{average_price:.2f} 元")
```
- **說明**：
  - 使用 `append()` 收集使用者輸入。
  - `tuple()` 將列表轉為元組。
  - `random.randint(10, 100)` 產生隨機價格。
  - 列表推導式創建巢狀列表，`sum()` 計算總價格。
- **範例輸出**：
```
請輸入第 1 個商品名稱：蘋果
請輸入第 2 個商品名稱：香蕉
請輸入第 3 個商品名稱：橘子
商品列表：['蘋果', '香蕉', '橘子']
商品元組：('蘋果', '香蕉', '橘子')
請輸入一個新商品名稱：葡萄
排序後的列表：['橘子', '葡萄', '蘋果', '香蕉']
商品與價格：[['橘子', 45], ['葡萄', 72], ['蘋果', 19], ['香蕉', 88]]
平均價格：56.00 元
```

## 7. 常見問題與疑難排解
- **問題**：`TypeError: 'tuple' object does not support item assignment`。
  - **解決**：元組不可變，無法直接修改，需轉為列表（`list(tuple)`）進行操作。
- **問題**：`IndexError: list index out of range`。
  - **解決**：檢查索引是否超出列表或元組長度。
- **問題**：排序失敗（例如 `sort()` 對混合型態列表）。
  - **解決**：確保列表元素型態一致，或使用自訂排序（後續週次介紹）。
