## 1. 運算子概述
運算子是 Python 中用於執行運算的符號，分為以下幾類：
- **算術運算子**：用於數值計算，如加減乘除。
- **比較運算子**：比較兩個值，傳回布林值 (`True` 或 `False`)。
- **邏輯運算子**：結合多個條件，進行邏輯判斷。

### 1.1 算術運算子
以下是常用的算術運算子：
- `+`：加法，例如 `5 + 3` → `8`。
- `-`：減法，例如 `5 - 3` → `2`。
- `*`：乘法，例如 `5 * 3` → `15`。
- `/`：除法（結果為浮點數），例如 `5 / 2` → `2.5`。
- `//`：整數除法（取整數部分），例如 `5 // 2` → `2`。
- `%`：模數（取餘數），例如 `5 % 2` → `1`。
- `**`：次方，例如 `2 ** 3` → `8`。

#### 程式碼範例 1：算術運算子
```python
# 算術運算示範
a = 10
b = 3

print(f"加法: {a} + {b} = {a + b}")
print(f"減法: {a} - {b} = {a - b}")
print(f"乘法: {a} * {b} = {a * b}")
print(f"除法: {a} / {b} = {a / b}")
print(f"整數除法: {a} // {b} = {a // b}")
print(f"模數: {a} % {b} = {a % b}")
print(f"次方: {a} ** 2 = {a ** 2}")
```
- **說明**：
  - 除法 `/` 總是傳回浮點數，而整數除法 `//` 只取整數部分。
  - 模數 `%` 常用於檢查是否整除。
- **預期輸出**：
```
加法: 10 + 3 = 13
減法: 10 - 3 = 7
乘法: 10 * 3 = 30
除法: 10 / 3 = 3.3333333333333335
整數除法: 10 // 3 = 3
模數: 10 % 3 = 1
次方: 10 ** 2 = 100
```

### 1.2 比較運算子
比較運算子用於比較兩個值，傳回布林值：
- `==`：等於，例如 `5 == 5` → `True`。
- `!=`：不等於，例如 `5 != 3` → `True`。
- `>`：大於，例如 `5 > 3` → `True`。
- `<`：小於，例如 `5 < 3` → `False`。
- `>=`：大於或等於，例如 `5 >= 5` → `True`。
- `<=`：小於或等於，例如 `5 <= 3` → `False`。

#### 程式碼範例 2：比較運算子
```python
# 比較運算示範
x = 7
y = 4

print(f"{x} == {y}: {x == y}")
print(f"{x} != {y}: {x != y}")
print(f"{x} > {y}: {x > y}")
print(f"{x} < {y}: {x < y}")
print(f"{x} >= {y}: {x >= y}")
print(f"{x} <= {y}: {x <= y}")
```
- **說明**：
  - 比較運算子常用於條件判斷，結果為 `True` 或 `False`。
- **預期輸出**：
```
7 == 4: False
7 != 4: True
7 > 4: True
7 < 4: False
7 >= 4: True
7 <= 4: False
```

### 1.3 邏輯運算子
邏輯運算子用於結合多個布林值：
- `and`：且，兩個條件都為 `True` 時傳回 `True`。
- `or`：或，至少一個條件為 `True` 時傳回 `True`。
- `not`：非，傳回相反的布林值，例如 `not True` → `False`。

#### 程式碼範例 3：邏輯運算子
```python
# 邏輯運算示範
age = 20
is_student = True

# 使用 and, or, not
can_vote = age >= 18 and is_student
has_access = age >= 18 or is_student
not_student = not is_student

print(f"可以投票嗎？{can_vote}")
print(f"有權限嗎？{has_access}")
print(f"不是學生？{not_student}")
```
- **說明**：
  - `and` 要求兩個條件都成立。
  - `or` 只要任一條件成立即可。
  - `not` 反轉布林值。
- **預期輸出**：
```
可以投票嗎？True
有權限嗎？True
不是學生？False
```

## 2. 條件控制：if/elif/else
Python 使用 `if`, `elif`, `else` 語句實現條件控制，根據條件執行不同的程式碼區塊。

### 語法結構
```python
if 條件1:
    # 條件1成立時執行
elif 條件2:
    # 條件2成立時執行
else:
    # 所有條件都不成立時執行
```
- **注意**：
  - 條件後必須加上冒號 `:`。
  - 縮排（通常 4 個空格）定義程式碼區塊。
  - `elif` 和 `else` 是可選的。

### 程式碼範例 4：簡單 if 語句
```python
# 檢查年齡是否成年
age = int(input("請輸入您的年齡："))

if age >= 18:
    print("您是成年人！")
else:
    print("您尚未成年。")
```
- **說明**：
  - `input()` 取得年齡並轉為整數。
  - `if` 檢查年齡是否大於等於 18，執行對應區塊。
- **範例輸出**：
```
請輸入您的年齡：20
您是成年人！
```

### 程式碼範例 5：使用 if/elif/else
```python
# 根據分數判斷等級
score = int(input("請輸入您的分數（0-100）："))

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(f"您的等級是：{grade}")
```
- **說明**：
  - 多個 `elif` 檢查分數範圍，依序執行第一個符合的條件。
  - `else` 處理所有未滿足的情況。
- **範例輸出**：
```
請輸入您的分數（0-100）：85
您的等級是：B
```

## 3. 巢狀條件語句
條件語句可以巢狀使用，即在 `if` 區塊內再包含 `if` 語句。

### 程式碼範例 6：巢狀 if
```python
# 檢查年齡與學生身份
age = int(input("請輸入您的年齡："))
is_student = input("您是學生嗎？(輸入 yes/no)：") == "yes"

if age >= 18:
    if is_student:
        print("您是成年學生，享有學生折扣！")
    else:
        print("您是成年人，但不是學生。")
else:
    print("您尚未成年。")
```
- **說明**：
  - 外層 `if` 檢查年齡，內層 `if` 檢查學生身份。
  - `input() == "yes"` 將輸入轉為布林值。
- **範例輸出**：
```
請輸入您的年齡：19
您是學生嗎？(輸入 yes/no)：yes
您是成年學生，享有學生折扣！
```

## 4. 課堂練習
請撰寫一個 Python 程式，完成以下任務：
1. 提示使用者輸入兩個數字。
2. 使用比較運算子判斷哪個數字較大，或是否相等。
3. 使用 `if/elif/else` 輸出結果，例如：「[數字1] 大於 [數字2]」或「兩個數字相等」。
4. 額外挑戰：檢查輸入是否為偶數（使用模數 `%`）並輸出結果。

### 參考解答
```python
# 取得兩個數字
num1 = float(input("請輸入第一個數字："))
num2 = float(input("請輸入第二個數字："))

# 比較大小
if num1 > num2:
    print(f"{num1} 大於 {num2}")
elif num1 < num2:
    print(f"{num1} 小於 {num2}")
else:
    print("兩個數字相等")

# 檢查是否為偶數（僅對整數有效）
if num1 % 2 == 0:
    print(f"{num1} 是偶數")
else:
    print(f"{num1} 是奇數")
```
- **說明**：
  - 使用 `float()` 允許輸入小數。
  - 模數 `%` 檢查是否能被 2 整除。
- **範例輸出**：
```
請輸入第一個數字：10
請輸入第二個數字：5
10.0 大於 5.0
10.0 是偶數
```

## 5. 常見問題與疑難排解
- **問題**：`IndentationError: expected an indented block`。
  - **解決**：檢查 `if`、`elif`、`else` 後的程式碼是否正確縮排（4 個空格）。
- **問題**：`ValueError` 當輸入非數字。
  - **解決**：目前使用 `int()` 或 `float()`，後續週次會介紹例外處理。
- **問題**：邏輯條件未如預期執行。
  - **解決**：檢查條件順序（`elif` 按順序執行）或使用 `print()` 檢查中間值。
